# 🕒 Digital Clock

A sleek and real-time digital clock web app built using **React** and deployed on **Vercel**.

⚡ This is my **first React project**, and I built it to learn the fundamentals of components, hooks, and real-time updates. Simple, but clean.


## 🚀 Live Demo

Check it out live here 👉 [https://digital-clock-snowy-five.vercel.app](https://digital-clock-snowy-five.vercel.app)

## 🛠️ Tech Stack

- ⚛️ React (Vite)
- 💅 CSS
- 🌐 Vercel for Deployment
